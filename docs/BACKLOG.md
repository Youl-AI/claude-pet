# 백로그

0.5.2 배포 시점(2026-08-29)에 남겨둔 개선 후보. 필수 항목은 없고 전부 선택이다.
전체화면 게임에서 펫이 숨는 것은 실게임으로 눈 확인 완료(2026-08-29).

## 기능

- **다중 모니터 지원** — 펫이 주 모니터에만 갇혀 있다(`SystemParameters.WorkArea` 한계).
  모니터 열거 + 모니터 간 이동 로직이 필요. 남은 항목 중 체감 가치가 가장 크다.
- **꾸미기** — 모자·옷·지팡이 같은 장식, 다른 동물 펫.
  스프라이트 파이프라인(`tools/spritegen/`)이 이미 스크립트화되어 있어 기반은 준비됨.
- **낮잠 중 리셋까지 남은 시간 표시** — 낮잠 스펙에서 의도적으로 범위 밖 처리했던 항목.
- **레벨업 때 명패도 같이 반짝** — 레벨 스펙 §6에 있었으나 구현되지 않고 남음.
  구현하거나 스펙에서 지워서 스펙과 구현을 일치시켜야 한다.
- **`quota_auto_resume_stale` / `disabled` 알림의 별도 연출** — 지금은 무시한다.

## 성능

- **TranscriptTail 배치 상한** — 상태 감지 경로에는 스캐너와 달리 줄 크기 상한이 없어,
  병리적 거대 줄(예: 8 MB) 유입 시 1회성 메모리 스파이크가 남아 있다(성장은 없음).
  실측 최대 줄은 2.39 MB라 실사용 영향은 작다. `TranscriptCostScanner`와 같은
  바이트 버퍼 + 상한 방식으로 맞추면 된다.
- **WPF 탈피(비추천)** — 바닥 ~60 MB를 20–30 MB대로 내리려면 Win32 재작성이
  필요하다. 비용 대비 무의미하다고 판단해 하지 않기로 함.

## 정리(사소)

- 레벨 최종 리뷰 잔여 Minor: `PlateRenderer` 글리프 로직을 PetCore로 옮겨 테스트
  가능하게(M5), 누운 포즈에서 명패 간격 4px vs 6px 불일치(M8), 스펙 §7.3의
  스캔 예산 문구가 현재 구현과 다름.
- `tools/spritegen/`과 flashgen의 상수가 손으로 복사되어 있음 — 한쪽을 바꾸면
  다른 쪽을 잊기 쉽다.
